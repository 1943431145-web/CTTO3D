一、项目概述
1.1 项目背景
肺癌是我国发病率和死亡率最高的恶性肿瘤之一，早期肺结节的及时发现与处理对患者预后至关重要。微波消融（Microwave Ablation，MWA）作为一种微创局部热消融技术，因其高效、低损伤、可重复操作的特点，已逐步成为早期肺结节治疗的重要手段。
然而，现有临床工作流程高度依赖医生个人经验：CT图像阅片、结节定性、进针路径规划、消融参数设置均需手动完成，存在操作差异大、耗时长、安全边界不精确等问题。
本项目旨在开发一套集CT影像智能读取、三维可视化重建、AI器官分割、肺结节自动识别、消融参数智能推荐、最优进针路径规划、消融热场实时仿真以及消融仪设备联动于一体的精确消融导航系统，以提高手术安全性、规范化程度和效率。
1.2 项目目标
构建完整的CT影像处理与三维重建流水线，支持临床常用DICOM格式
实现基于深度学习的多器官自动分割（肺实质、血管树、气道、胸壁）
实现肺结节三维自动识别与精准定位，灵敏度 > 95%，检测耗时 < 30s
提供智能消融参数决策引擎（针型、功率、时间、安全边界）
提供基于约束优化的最优进针路径规划模块，自动规避高风险结构
提供基于有限元/热传导模型的消融热场仿真可视化
实现与消融仪设备的串口/网络实时通信与参数闭环控制
预留数据库、机械臂辅助、AR导航等后期扩展接口
1.3 适用用户
1.4 项目范围
本期（V1.0）开发范围：CT图像导入与预处理、三维重建与多器官分割、肺结节自动识别与特征分析、消融参数推荐、进针路径规划、消融热场仿真、消融仪通信接口、基础UI框架与患者管理。
本期不包含（预留后期）：远程PACS数据库对接、机械臂控制协议实现、AR导航渲染、多中心数据共享平台、临床验证数据库、手术报告自动生成系统。

2.2 技术选型
2.2.1 前端UI框架
开发语言：C++ (Qt6) 或 Python (PyQt6 / PySide6)
3D渲染引擎：VTK 9.x（体绘制、表面渲染、剪裁平面）
AI推理后端：ONNX Runtime（支持GPU加速，TensorRT可选）
界面风格：现代扁平风格，主色调深蓝/白，支持白天/夜间模式切换
2.2.2 后端算法框架
医学图像处理：ITK（配准、分割、特征提取）
深度学习：PyTorch + nnU-Net（器官分割）/ LUNA16训练的3D CNN（结节检测）
路径规划：A*算法 + 距离变换碰撞检测，基于Dijkstra/RRT的候选路径评分
热场仿真：生物热传导方程（Pennes BHTE）有限元求解，支持各向异性组织参数
2.2.3 设备通信
消融仪接口：RS-232/RS-485串口协议（波特率可配），支持Modbus RTU兼容帧格式
网络扩展：TCP/IP Socket，支持局域网内多设备接入
机械臂预留：ROS2消息接口（sensor_msgs, geometry_msgs），UDP实时状态流

三、详细功能需求
3.1 CT影像导入与预处理模块
3.1.1 功能描述
系统支持从多种来源导入CT扫描数据，并进行标准化预处理，为后续三维重建提供高质量输入。
3.1.2 功能需求清单
3.1.3 性能指标
导入速度：单序列500张切片完成导入解析时间 < 5秒
兼容格式：符合DICOM 3.0标准，兼容主流CT设备（GE、Siemens、Philips、联影、东软等）
重采样精度：各向同性体素插值误差 < 0.1 mm
3.2 三维重建引擎
3.2.1 功能描述
基于导入的CT序列，实时生成高质量三维体积模型，支持多种渲染模式，提供直观的三维解剖视图。
3.2.2 功能需求清单
3.2.3 性能指标
重建速度：500层CT序列完成三维重建 < 10秒（GPU加速）
渲染帧率：交互旋转操作帧率 >= 30 FPS（RTX 3060 Ti 环境下）
分辨率：支持最小体素尺寸 0.5 mm × 0.5 mm × 0.5 mm
3.3 器官精确分割模块
3.3.1 功能描述
运用基于深度学习的自动分割算法，对CT影像中的关键解剖结构进行精确的语义分割，为路径规划和消融仿真提供精确的空间约束数据。
3.3.2 分割目标清单
3.3.3 功能需求
一键全自动分割：单击启动，自动完成所有目标结构分割，耗时 < 60秒（GPU环境）
手动修正工具：提供笔刷（添加/擦除）、种子点扩展、等值线编辑等手动修正工具
分割结果导出：支持将分割Mask导出为NIfTI格式，供第三方工具使用
置信度显示：对每个分割结构显示AI置信度热力图，方便医生快速识别低置信区域
3.4 肺结节自动识别模块
3.4.1 功能描述
在三维CT体积内自动搜索、检测并定位肺结节，对每个候选结节提供详细的量化特征分析，输出结节风险评分，辅助医生制定治疗决策。
3.4.2 检测能力指标
3.4.3 结节特征分析输出
形态学参数：最大径（长轴/短轴/Z轴）、体积（mm³）、球形度（Sphericity）、毛刺征评分
密度特征：CT衰减值（HU均值/峰值/标准差）、实性成分比例、磨玻璃成分占比
位置描述：所在肺叶（左上/左下/右上/右中/右下）、与胸膜距离、与最近血管的距离、与气道距离
风险评估：参照Lung-RADS 1.1分级规则，自动输出1-4X类分级及推荐随访/治疗建议
历史对比：若存在历史CT，自动计算结节体积倍增时间（VDT）
3.5 消融参数智能决策模块
3.5.1 功能描述
根据结节特征分析结果，结合预设的医学知识规则库与机器学习模型，自动推荐消融针型号、消融功率、消融时间及安全边界参数，支持医生手动覆盖调整。
3.5.2 决策参数说明
3.5.3 功能需求
参数推荐耗时 < 2秒，以非模态弹窗形式展示推荐值及依据说明
所有推荐参数支持医生手动修改，修改后自动重新计算预期消融区
针对特殊情况（近心脏、贴近大血管等）自动弹出高风险提示弹窗
参数决策规则库支持后台配置更新，无需重新编译程序
3.6 最优进针路径规划模块
3.6.1 功能描述
在三维解剖空间内，综合考虑结节位置、器官分割结果、危险结构安全边界等约束条件，自动计算并推荐最优进针路径，并支持多路径比较和手动调整。
3.6.2 路径评分规则
3.6.3 功能需求
自动规划耗时 < 5秒，一次性输出 Top-3 候选路径供医生选择
3D可视化路径：在三维模型上以彩色线段叠加显示路径，不同颜色代表不同评分等级
路径参数显示：进针角度（θ、φ双角度）、进针深度、经皮入点坐标（相对体表标志点）
手动调整：支持在3D视图中拖动针道端点，实时更新路径评分，碰撞检测实时反馈
多针规划：支持双针同时规划，自动优化两针的相对空间关系以实现最优消融覆盖
3.7 消融热场仿真模块
3.7.1 功能描述
基于Pennes生物热传导方程，对消融过程中的温度场时空分布进行数值仿真，预测消融损伤边界，帮助医生在术前验证消融方案的有效性和安全性。
3.7.2 仿真模型参数
3.7.3 功能需求
实时预计算：参数确认后，仿真计算时间 < 10秒（GPU有限元加速）
动态播放：支持0~T_end时间轴拖动，动态播放温度场扩散过程
等温线叠加：在3D模型上渲染60°C/80°C/100°C等温面，以不同透明度叠加显示
安全边界验证：自动检测消融区是否完整覆盖结节（含安全边界），不足区域以红色高亮提示
危险结构热效应：显示高温区域与相邻血管、心脏、食管的最近距离，超阈值（≥60°C）即报警
3.8 消融仪连接与实时控制模块
3.8.1 功能描述
通过串口或网络接口与消融仪建立实时双向通信，支持参数下发、状态读取、报警响应及紧急停止功能，实现软件系统与硬件设备的闭环控制。
3.8.2 通信协议规范
物理层：RS-232 / RS-485（DB9接口），波特率：9600~115200 bps（可配）
帧格式：帧头（2字节固定标识）+ 命令字（1字节）+ 数据长度（1字节）+ 数据域（N字节）+ CRC16校验（2字节）+ 帧尾（1字节）
心跳检测：系统每500ms发送心跳包，超过2s无响应触发连接断开警告
并发保护：串口通信采用互斥锁机制，防止多线程竞争导致帧错乱
3.8.3 控制功能需求
四、UI界面设计需求
4.1 整体设计原则
手术室环境适配：暗色主题（深蓝/深灰底色）为主，减少手术室强光环境下屏幕反光干扰
大字体与高对比度：操作状态文字 >= 14pt，关键数据 >= 18pt，符合WCAG 2.1 AA级对比度要求
单手/触屏友好：主操作区大按钮（最小 44×44 px），支持触摸屏操作
零学习成本流程：主界面按手术流程顺序布局（导入→建模→分割→识别→规划→仿真→手术），步骤进度条清晰可见
无打扰通知：报警信息以闪烁红色区域 + 语音提示形式呈现，不遮挡主要操作区域
4.2 主界面布局规范
4.3 3D交互视图设计
多视图模式：全屏3D视图、三联MPR视图（轴/矢/冠）、四分屏视图（MPR×3 + 3D），一键切换
结构图层控制：右键菜单或侧边栏控制各解剖结构的显示/隐藏/透明度（类似Photoshop图层面板）
路径叠加显示：消融针路径以彩色圆柱体形式在3D视图中显示，支持拖拽修改进针深度
仿真叠加显示：消融热场以半透明彩虹色等温面叠加在3D解剖模型上，可调节叠加透明度
截图与录屏：一键截取当前视图（含参数标注），支持录制手术操作过程视频

六、非功能性需求
6.1 性能需求汇总
6.2 可靠性需求
系统连续运行稳定性：单次手术会话（最长6小时）内不发生崩溃或内存泄漏
数据保护：影像处理过程中发生异常时，自动保存当前分割/规划结果至临时文件，重启后可恢复
设备断联处理：消融仪连接异常时，系统立即触发声光报警并暂停一切参数下发操作
操作日志：记录所有用户操作（含时间戳、操作人、操作类型），保留至少2年，供审计追溯
6.3 安全性需求
用户权限管理：分级权限（管理员/主治医生/助手），关键操作（紧急停止、参数修改）需主治医生权限
消融安全联锁：VSWR > 3.0、输出功率异常偏差 > 20%、天线温度 > 80°C，任一条件触发硬件紧急停止
数据隐私合规：患者个人信息加密存储（AES-256），传输采用TLS 1.3，符合《医疗数据安全规范》要求
法规合规：系统软件按医疗器械软件生存周期过程（IEC 62304 Class B）开发，界面与文档支持中/英双语
6.4 可维护性需求
模块化设计：各功能模块以独立可替换组件实现，算法版本可热更新（不停机升级AI模型）
配置文件管理：所有可调参数（消融规则库、设备通信参数、仿真物理参数）均以JSON/YAML格式配置文件管理，支持界面内直接编辑
日志与诊断：分级日志系统（Debug/Info/Warning/Error），支持远程日志采集供技术支持分析
单元测试覆盖率：核心算法模块（分割后处理、路径规划、仿真计算）单元测试覆盖率 >= 80%
